# 退回修订重提的 HTTP 故障回归与人工检查

基线为 `f6ca923f8ce51a4f9a9b97c1c8b8ec6aaeff4a07`。本组补充真实 Chromium 与真实 loopback HTTP 连接上的故障验证；业务服务和申请记录全部是内存合成夹具，不运行 Nest、数据库、角色迁移或通知投递。它不是新的真实后端/数据库联调，不替代原 f6ca923f / 923c6c57 的真实验收。

已有 `simple_return_render_pass.py` 覆盖退回、保存及正常重提，也覆盖首次未知请求后来被退回；`simple_review_pending_render_pass.py` 覆盖已发送意图保留。但它们使用 Playwright Route 返回或中止请求，未验证第二次提审在实际 HTTP 服务受理后丢失响应。

## 自动化运行

恢复锁定依赖，在此工作树启动仅监听 loopback 的 Vite；不要启动后端，也不要配置现有 API 地址。

```bash
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

按启动日志的实际端口运行；下列默认值只用于本地测试，不是开放入口：

```bash
PYTHONDONTWRITEBYTECODE=1 RP_BASE=http://127.0.0.1:8848 \
  RP_NETWORK_EVIDENCE=/tmp/srvf-return-network \
  python -u tests/render/simple_return_network_render_pass.py
```

复用环境已有的 Playwright 和 `/usr/bin/chromium`，不新增项目依赖。`RP_NETWORK_CASES` 可选 `drop-after-accept` 或 `reload-after-accept`，用于只重试失败用例。默认执行两种情况：

1. HTTP 服务已记录第二次申请后，不发送响应头，直接关闭 TCP 连接；页面显示未知结果，再刷新和轮询。
2. HTTP 服务已记录第二次申请，响应仍被屏障阻塞；此时刷新页面，再释放原连接。客户端取消不被当作服务端取消。

两种情况均通过实际页面完成首次提审、显示合成退回意见、修改与保存、新键新版本重提。重复点击发生在第二次提审及恢复请求各自确实在途时。一般 GET 与刷新必须保留原三字段请求体，不自动 POST、不解除编辑限制或生成替代键；只有用户明确确认的同键同体重放成功后才能归档。重放后继续刷新，活动仍为 draft，申请记录只有 v1 returned / v2 pending，旧原因与修改内容保留。

每例预期为 **3 次 HTTP 提审尝试、2 个不同操作键、2 条合成申请记录**：首次提审、丢响应的第二次提审、对第二次的原样恢复。恢复的第三次 HTTP 尝试不能新增第三条申请；重复点击不能增加 HTTP 尝试。服务端不会记录登录体、令牌、Cookie 或请求头。Playwright 网络路由只阻止外部地址，业务 API 均经 HTTP 服务，断连接由服务端 socket 实施。

输出包括每例 `result.json`、HTTP 事件和内存状态、故障及恢复截图；失败记录保留。服务在 `finally` 关闭，浏览器也会关闭；测试结束还需停止本轮启动的 Vite。

## 人工最小检查（已有授权的隔离测试环境）

不在此文档提供账号、密码或开放地址，不创建权限。使用已经准备好的角色：普通组织者须为活动组织的正式成员、命中责任范围，并具必要的组织范围创建/修改资格；创建正常 V5 时还需既定的默认时长及贡献政策选择资格。审核员须是不同身份，具该组织的审核读取及退回资格。组织者不要兼授审核员权限；另有一个无关成员做不可见性检查。

1. 组织者从活动页“筹备单场次活动”创建正常 V5 草稿，核对固定“先到先得”、场次与默认政策，保存并提审。预期为待审，不是已发布。
2. 不同审核员在待审列表打开该申请，填写明确原因并退回。预期本次记录为 returned，原因可追溯。
3. 组织者从同浏览器“我在本设备打开过的活动草稿”或已收藏的详情链接返回，点击“读取草稿”。预期看到原文退回原因，无需审核员权限；普通活动列表不保证能找到草稿。
4. 点击“按意见修改草稿”，修改“参与准备”，保存，核对已保存内容，再勾选并重提。预期是新的操作键、版本及待审申请；旧原因保留，活动仍为 draft。
5. 故障恢复使用上述受控 HTTP 屏障；不要仅靠手动断网推断请求已受理。出现未知结果后保留原标签页，刷新与读取状态不应生成替代意图；选择“继续核对上次提审”并明确确认后，预期原样恢复原回执，不新增第三条申请。
6. 无关成员不能读取该组织者的草稿；组织者不能借该入口读取审核员详情或执行审核决策。拒绝后不添加权限以使测试通过。

跨设备、已关闭标签页的完整恢复尚未实现；清除浏览器数据会丢失本机记录。专业配置、覆盖项、变更审核的完整处理仍禁用；资格排序与抽签不能在简单流程切换。本轮不执行审核通过发布、外部通知、部署、合并或公网开放。
