## 前端边界两项失败（仅客户端，待修复、待服务端核验）

这两项来自独立前端边界单测，不是本批源站办理中已证实发生的重复写入，也尚未批准修改产品或扩大验收命令。

1. **报名中表单版本失效后，同页没有刷新定义的入口。** 同一页面再次提交仍会使用旧版本；退出后重新进入并重选可以得到新版本。复现条件是报名过程中表单被修改。目前只在客户端单测中看到。
2. **资格排序手工录取在请求回报成功后，列表仍可能把同一行显示为待录取。** 页顶可已显示已录取，行内按钮仍可用，并可再次发出录取请求。该现象在伪造传输层和页面模拟环境中可以复现；真实服务端是否会出现这一矛盾、第二次写入会有什么后果，尚未验证。不得据此断言本批现场已经发生重复写入。
